# Armwise neutral-spine source check

Status as of 2026-08-16: **no public implementation was located**, so no code is
copied or attributed as an implementation of this method.

A Vesuvius Discord message described using an “armwise neutral-spine” on bent
scrolls. Before integrating it, we searched the public GitHub account matching
the Discord handle, all eight public repositories and their public branches,
public gists and activity, GitHub code/commit search, Sourcegraph, web search, and
the local two-month Discord archive. No matching source, path, commit, or
algorithm specification appeared.

Search terms included both `neutral-spine` and `neutral spline`, with and without
`armwise`, plus repository searches for `spine`, `spline`, `umbilicus`, and
`centerline`. Public search results are time-dependent; the commit heads below
identify the most relevant repositories as they existed on the stated date.

This is an absence-of-public-source report, not proof that the method does not
exist. It may be private, unpushed, attached only in Discord, or described under
another name. An exact source URL plus license is required before integration.
Until then, this project uses its independently specified adaptive midpoint
audit and does not present a guessed spline as someone else’s method.
