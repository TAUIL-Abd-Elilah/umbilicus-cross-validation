# Manual review screenshots

Store evidence under `manual/screenshots/<scroll>/`. Each filename must contain
the scroll ID. Approval requires decodable PNG/JPEG images at least 256x256 and
at least one filename token for each of `_start`, `_middle`, and `_end`. Every filename must also
contain the displayed `z<integer>` token (for example `PHerc1203_middle_z9968.png`); the required
three must be distinct and strictly ordered by z. Add every ambiguous transition and original
score-0 location as well.
